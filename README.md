# kisstack/reusable-workflows

Pinned, reusable GitHub Actions workflows for KISStack-built projects: the unprivileged build and the separate attest job (Threat Model §5). Projects call them by full commit SHA; the deployer and the Policy service pin that SHA (WORKFLOW_SHA).

Public by decision D-2026-10-14-04. Changes are reviewed in wojimene/kisstack first.
